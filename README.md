# 브레인무브: 무지개 마을

노인을 위한 **카메라 동작 인식 신체활동 + 인지 훈련 게임**입니다. 웹캠 앞에서 몸을 움직이면 게임이 동작을 알아보고, 기억력·집중력·판단력을 함께 훈련해요. 혼자 또는 카메라 하나로 둘이(협동·대결·릴레이) 할 수 있어요.

▶ **바로 하기:** https://tazan12.github.io/brainmove/ (크롬 + 웹캠)

## 게임 9가지

| 영역 | 게임 | 몸 동작 | 훈련 |
|---|---|---|---|
| 기억력 | 흥부자 댄스 무대 | 만세·팔 들기·스쿼트/앉아서 무릎 들기 | 순서 기억(작업기억) |
| 기억력 | 장독대 짝 맞추기 | 팔 뻗기 | 시공간 기억 |
| 기억력 | 오일장 장보기 | 팔 뻗기 | 단어·일화 기억 |
| 집중력 | 무지개 풍선 시장 | 팔 뻗기·몸통 회전 | 선택적 주의(스트룹) |
| 집중력 | 밤하늘 별자리 잇기 | 대각선 팔 뻗기 | 처리속도·주의 전환 |
| 집중력 | 풍물 장단 놀이 | 박수·만세·팔 들기 | 리듬·타이밍 |
| 판단력 | 징검다리 OX 계산 | 만세(O)·팔 X 자 | 계산·판단 |
| 판단력 | 과수원 수확 | 빠른 손 뻗기·참기 | 반응억제(Go/No-Go) |
| 판단력 | 청홍 초롱 신호 | 왼팔·오른팔 | 인지 유연성(규칙 전환) |

- 서서 / 앉아서 모드(앉아서는 의자에서 할 수 있는 동작만)
- 난이도 1~10단계 자동 조절, 아침 체조 → 게임 → 쉬는 시간 → 노을 스트레칭 코스
- 성우 5명(무브 선생님·흥부자 MC·어전 내관·열혈 캐스터·꼬마 응원단, Gemini TTS 녹음), 테마 배경음악
- 참여자 등록·로그인, 관리자 PIN, 기록·추이, CSV 내보내기, 정원 키우기

## 개인정보
- 카메라 영상은 **브라우저 안에서만** 처리하고 저장하거나 전송하지 않아요(MediaPipe Pose).
- 참여자 이름과 기록은 그 컴퓨터 브라우저(localStorage)에만 저장돼요.
- 게임 기록은 훈련 참고값이며 진단 결과가 아니에요.

## 폴더
- `index.html` — 배포용 게임 한 장(3D 인물 포함)
- `assets/` — 민화풍 그림, 테마 음악(`music/`), 성우 음성(`voice/`, `index.js`가 목록)
- `src/` — 소스(core·pose·fx·narrator·games·games2·app·avatar), `build.py`로 묶음
- `voicegen/` — 성우 음성 녹음기(Gemini TTS). API 키는 `_secret/gemini_key.txt`(저장소에 올리지 않음)

## 다시 만들기
```bash
python3 build.py        # src/ → dist/brainmove.html  (models/Michelle.glb 필요: Mixamo 캐릭터, 저장소에는 미포함)
node voicegen/lines.mjs # 대사 목록 갱신
node voicegen/gen.mjs voice   # 녹음(하루 한도 내에서 이어서)
```

만든 사람: 김정호 (경민대학교 간호학과)
